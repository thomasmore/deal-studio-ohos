What was actually verified

  • Host: 35 app-plan checks and 16 other suites. All eight original sources plus the follow-up pass real compiler/VM smoke. Shopping ownership, checked counts and direct handler isolation pass host replay.
  • Native notes: nine recorded stages covering empty/fresh drafts, Save, Cancel, edits and system Back. Delete was not exercised.
  • Native shopping: four captured stages through isolated per-list items. Checked state and shared-count update were not completed natively.
  • Initial-run gaps: notes c_delete and shopping c_removeList exist but have no UI binding. Compilation and structural smoke do not establish requested-action coverage.
  • Review: both MEDIUM reproductions now have regressions and fixes: empty active views and pre-edit screen preservation.

Interpretation and safety

This small one-pass set does not establish variance or linear scaling. Active time excludes clarification waits (none here). Timing, mocked host effects and native evidence remain separate. Books/medicines behavior and process-restart persistence were not fully verified.
