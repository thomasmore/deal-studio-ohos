FULL-CANVAS APPS
This request is a game, a toy, a simulation or a drawing: something that moves on its own or is touched anywhere.
Build it on one ui.Surface drawn with std/gfx, not out of buttons, cards and grids.

The shape of the program:
- view(state) returns ui.AppTheme(preset, "", [ui.Surface("fill", 360, 640, "draw", "onFrame", "onPointer")]).
  Nothing else goes in the view unless the request asks for controls outside the drawing. What the person reads -- a
  score, a count, a title, a message -- is drawn on the surface with gfx.text.
- 360 by 640 is the surface for a portrait app. Use 640 by 360 only when the request is clearly landscape.
  Every position, size and speed is in these units; the phone scales the whole surface to fit.
- draw(state: AppState): gfx.Shape[] builds a local gfx.Shape[], pushes shapes back to front and returns it.
  The background rect comes first and the HUD last. draw only reads state.
- onFrame(state: AppState, elapsedMs: number): AppState runs before every frame, about 60 times a second.
  Start it with let dt: number = math.min(elapsedMs, 50) / 1000; and move everything by speed * dt,
  with speeds in units per second. Return state unchanged while nothing is moving.
- onPointer(state: AppState, p: gfx.Pointer): AppState gets every finger event: p.phase is "down", "move", "up" or "cancel",
  p.x and p.y are in surface units, and p.id tells two fingers apart.

State:
- A game with rounds keeps a phase string in AppState: "ready" before the first round, "playing", "over" at the end;
  "ready" and "over" draw the title or the result over the scene with what to tap, and a pointer "down" in either
  starts a fresh round. A toy, a simulation or a scene to watch runs from the start and needs no phase. Never make a
  ui.Button the only way to start or restart.
- One record class per kind of thing (class Ball { x: number; y: number; vx: number; vy: number; }), and an array of
  records for many of them. Keep counts, timers, a score and a random seed as numbers. AppState holds no gfx.Shape.
- State is immutable here too: onFrame builds new arrays and new records with a loop every frame and returns a new
  AppState with every field. Never assign into an array or a record that came from state.
- Count down timers with elapsedMs: spawnIn = spawnIn - elapsedMs; when it reaches 0, spawn and reset it.
- Random choices use math.randomStep(seed) and math.randomBelow(seed, n), with the seed kept in state and advanced
  each time.
- Build layouts with loops (rows times columns, a ring), never as long literal arrays.

Controls -- choose what fits and say it on the surface in a few words:
- Drag: while a finger is down, the thing it holds follows p.x (and p.y if it moves freely), clamped to the surface.
  Remember the finger with a dragging boolean or its p.id.
- Tap: a "down" anywhere does the one action (fires, jumps, adds, picks).
- Two jobs at once (move and act): the left half of the surface is a stick -- on "down" there,
  store the finger's id and where it went down; on "move", the offset from that point (capped at 50) is the direction
  and speed; on "up", stop. A "down" on the right half fires. Draw the stick as a ring with a knob where the finger is.
- Keep every control reachable with a thumb, and draw it, so the person can see what to touch.
- With a stick or on-screen buttons, the play area is the top of the surface and ends at y = 500; the stick and the
  buttons sit in the strip under it (y 500 to 640) on a background of their own. Nothing that matters is placed or
  moves into that strip: a thumb on the stick would hide it.

Movement and collisions:
- Bounce off a wall: reverse that velocity component and put the object back inside, so it cannot stick.
- Circle against circle: gfx.distance(x1, y1, x2, y2) < r1 + r2.
- Circle against a rect: the nearest point of the rect is (math.max(rx, math.min(cx, rx + rw)), the same for y);
  a hit when gfx.distance from the centre to it is less than the radius. Reverse vy when the ball hit the top or bottom
  face and vx when it hit a side, then move it out.
- Point in a rect: gfx.inside(px, py, x, y, width, height).
- A paddle that steers the ball: set vx from where the ball hit it, (ball.x - paddle centre) / half width * a top speed.
- Heading: a shape drawn pointing right (+x) and turned by math.atan2(dy, dx) * 180 / math.pi() degrees in gfx.group
  points along (dx, dy). Moving along an angle a in degrees: dx = math.cos(a * math.pi() / 180), dy = math.sin(...).
- Remove what leaves the surface or expires. Keep moving things under about 200 and the shapes drawn per frame under
  about 1500.
- Something that chases: moves toward its target, turns by a few degrees per frame, acts on a timer with a random delay.

Drawing:
- gfx.group(x, y, rotation, scale, alpha, shapes) draws shapes made around 0, 0 at x, y: write a thing once, around its
  own centre, and place it with a group. A part that turns on its own is a group inside the thing's group.
- Everything that moves must read at a glance at its real size: a silhouette of 3 to 6 shapes, not a square in a square,
  with the part that shows which way it faces plainly visible and sticking out, and the whole group turned to its
  heading. Things on different sides differ in colour and in shape.
- Obstacles are laid out separately with lanes and gaps between them, never one solid block, with an open way between
  where things appear and where the person is. What can be broken away is built of small tiles in a grid, removed one at
  a time.
- "Pixel", "retro" or "8-bit": draw sprites and walls from squares on a grid (a pixel of 3 or 4 units), a palette of a few
  flat colours, a dark plain background; no rounded rects, no glow, no gradients.
- Shapes computed at run time: a star, a gear or an asteroid is a polygon whose points come from a loop with
  math.cos and math.sin. A wheel of fortune, a pie chart or a pizza is slices of gfx.sector(x, y, radius, start, sweep,
  colour), each starting where the last ended (n slices of sweep 360 / n), in a gfx.group turned by the wheel's angle;
  not polygons or thick arcs.
- Depth and light: a ball, a planet or a bubble is a circle filled with gfx.radial, a light colour first, centred a little
  up and left of the middle, the darkest last; the sky, the sea or a metal bar is gfx.linear; a thing standing on the
  ground has a soft gfx.shadow under it ("#00000055"); a lamp, a star or a spark is in a gfx.glow; overlapping lights are
  in gfx.blend("add", ...). An effect costs a frame time: put it on the few things that matter, not on every particle.
- Glow, for "neon" or "glowing": the shape in gfx.glow of its own colour, on a near-black background, a few saturated
  colours, thin bright lines and glowing text.
- Particles for a hit or an explosion: a few short-lived records with a velocity and an age, drawn as circles or arcs
  that fade with group alpha 1 - age / lifetime.
- What the person reads: gfx.text(20, 34, 22, "left", ...) at the top left, counts as small shapes under it. Keep the top right corner (x over 260, y under 70) empty: the phone draws its own buttons there.
  Use ui.numberToString for numbers in text.
- A "ready" or "over" overlay is a translucent rect over the whole surface ("#000000aa") with centred text on it.

A complete example of these parts in one program, with no game in it. Write your own program for the request; take
the structure and the calls from this, not its things.

--- EXAMPLE ---
@jsonable
class Ball {
  x: number;
  y: number;
  vx: number;
  vy: number;
  hue: number;
}

@jsonable
class AppState {
  balls: Ball[];
  held: number;
  finger: number;
  seed: number;
}

function init(): AppState {
  let balls: Ball[] = [{x: 120, y: 200, vx: 90, vy: 140, hue: 0}, {x: 240, y: 420, vx: -120, vy: 60, hue: 1}];
  return {balls: balls, held: -1, finger: -1, seed: 20261116};
}

function radius(): number {
  return 26;
}

function onFrame(state: AppState, elapsedMs: number): AppState {
  let dt: number = math.min(elapsedMs, 50) / 1000;
  let r: number = radius();
  let balls: Ball[] = [];
  let i: number = 0;
  for (let b: Ball of state.balls) {
    if (i === state.held) {
      balls.push(b);
    } else {
      let x: number = b.x + b.vx * dt;
      let y: number = b.y + b.vy * dt;
      let vx: number = b.vx;
      let vy: number = b.vy;
      // Off a wall: turn that way round and put it back inside, so it cannot stick.
      if (x < r) { x = r; vx = math.abs(vx); }
      if (x > 360 - r) { x = 360 - r; vx = -math.abs(vx); }
      if (y < 80 + r) { y = 80 + r; vy = math.abs(vy); }
      if (y > 640 - r) { y = 640 - r; vy = -math.abs(vy); }
      balls.push({x: x, y: y, vx: vx, vy: vy, hue: b.hue});
    }
    i = i + 1;
  }
  return {balls: balls, held: state.held, finger: state.finger, seed: state.seed};
}

function ballAt(state: AppState, x: number, y: number): number {
  let i: number = 0;
  let found: number = -1;
  for (let b: Ball of state.balls) {
    if (gfx.distance(x, y, b.x, b.y) < radius() + 8) {
      found = i;
    }
    i = i + 1;
  }
  return found;
}

function onPointer(state: AppState, p: gfx.Pointer): AppState {
  if (p.phase === "down") {
    let hit: number = ballAt(state, p.x, p.y);
    if (hit >= 0) {
      return {balls: state.balls, held: hit, finger: p.id, seed: state.seed};
    }
    if (state.balls.length() >= 12 || p.y < 80) {
      return state;
    }
    let seed: number = math.randomStep(state.seed);
    let a: number = math.randomBelow(seed, 360) * math.pi() / 180;
    let balls: Ball[] = [];
    for (let b: Ball of state.balls) {
      balls.push(b);
    }
    balls.push({x: p.x, y: p.y, vx: 130 * math.cos(a), vy: 130 * math.sin(a), hue: state.balls.length() % 3});
    return {balls: balls, held: -1, finger: -1, seed: seed};
  }
  if (p.id !== state.finger || state.held < 0) {
    return state;
  }
  if (p.phase === "move") {
    let balls: Ball[] = [];
    let i: number = 0;
    for (let b: Ball of state.balls) {
      if (i === state.held) {
        balls.push({x: math.max(radius(), math.min(360 - radius(), p.x)), y: math.max(80 + radius(), math.min(640 - radius(), p.y)),
          vx: b.vx, vy: b.vy, hue: b.hue});
      } else {
        balls.push(b);
      }
      i = i + 1;
    }
    return {balls: balls, held: state.held, finger: state.finger, seed: state.seed};
  }
  return {balls: state.balls, held: -1, finger: -1, seed: state.seed};
}

function colourOf(hue: number): string {
  if (hue === 0) {
    return "accent";
  }
  if (hue === 1) {
    return "warning";
  }
  return "#22c55e";
}

function draw(state: AppState): gfx.Shape[] {
  let shapes: gfx.Shape[] = [];
  shapes.push(gfx.rect(0, 0, 360, 640, "background"));
  let r: number = radius();
  for (let b: Ball of state.balls) {
    let body: gfx.Shape[] = [gfx.circle(0, 0, r, colourOf(b.hue)), gfx.circle(-8, -8, 7, "#ffffff66")];
    shapes.push(gfx.group(b.x, b.y, 0, 1, 1, body));
  }
  shapes.push(gfx.text(20, 34, 18, "left", "ink", ui.numberToString(state.balls.length()) + " balls", true));
  shapes.push(gfx.text(20, 58, 14, "left", "soft", "Drag a ball, tap to add one"));
  return shapes;
}

function view(state: AppState): ui.View {
  return ui.AppTheme("clean", "", [
    ui.Surface("fill", 360, 640, "draw", "onFrame", "onPointer")
  ]);
}
